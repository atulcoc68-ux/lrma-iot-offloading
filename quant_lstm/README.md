# LSTM Quantization — `quant_lstm/`

Quantization benchmark for the **LSTM arrival-state predictor** from the
LRMA IoT offloading paper.

> **Scope**: Only `quant_lstm/` is added. Zero changes to `multitask_multilevel/`.

---

## Prerequisites

Python ≥ 3.10, pip, internet access (for pip install).

---

## Setup

```bash
# 1. Create and activate a virtual environment
python3 -m venv quant_venv
source quant_venv/bin/activate          # Windows: quant_venv\Scripts\activate

# 2. Install dependencies
pip install torch numpy pandas onnx onnxruntime
```

---

## Run

```bash
# From the repo root (where quant_lstm/ lives)
cd quant_lstm

# Default: 5 seeds × 300 epochs, batch 16, 1000 latency runs
python quantize_lstm.py

# Explicit options
python quantize_lstm.py \
    --epochs 300 \
    --seed0 42 \
    --data-dir ../multitask_multilevel/data \
    --out-dir . \
    --batch-size 16 \
    --lat-runs 1000 \
    --calib-samples 200 \
    --train-frac 0.8

# Quick smoke test
python quantize_lstm.py --epochs 50 --lat-runs 100
```

Expected runtime: ~5–15 minutes on a modern CPU (5 seeds × 300 epochs).

## Architecture

| Property | Value | Source |
|---|---|---|
| Class | `LSTM` + `LSTM_Cell` (custom) | `memory.py` L15-54 |
| `in_dim` / `hidden_dim` | 9 / 9 | `memory.py` L244 |
| Layers | 1 | `memory.py` L40 |
| Window (seq length) | 5 | `multitask.py` L186 |
| h/c init | `torch.zeros` (LSTMWrapper) | all variants |
| Output range | (0, 1) via final sigmoid | `memory.py` L33 |
| Loss | `nn.BCELoss` with clamped targets | `memory.py` L285 |

> [!WARNING]
> The original repo passes un-clamped targets to `nn.BCELoss`. Feature[1]
> (sum(cpu_milli)/50000) can reach ~19× in the dataset. See `results.md`
> for the full audit. Our script clamps targets to [0,1] and reports the
> fraction of affected values.

---

## Static PTQ Approach

| Property | Choice |
|---|---|
| Backend | `fbgemm` |
| Method | FX: `prepare_fx` / `convert_fx` on `LSTM_Cell` submodule only |
| Weight observer | `PerChannelMinMaxObserver`, qint8, per-channel symmetric |
| Activation observer | `HistogramObserver`, quint8, per-tensor affine |
| Cell state c | float32 naturally (never enters a quantized Linear) |
| Outer loop | stays in float32 (FX cannot trace `for seq_x in x` over a Proxy) |
| Calibration data | training windows only (time-based split) |

---

## Train / Eval Split

Split by **time slot** (not random) to avoid future leakage:

- **Train**: time slots `[0, cutoff_time)` — 80% of slots
- **Eval**: time slots `[cutoff_time, 29]` — 20% of slots
- Static PTQ calibration uses **training windows only**

`multitask.py` has hardcoded Windows paths (`curPath = 'C:/Users/HX/...'` in
`config.py`) and `data/gpunode.csv` is empty (header only). Running the eval
script requires editing repo files — outside scope.
