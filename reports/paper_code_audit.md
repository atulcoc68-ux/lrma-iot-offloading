# IEEE TNSE 2025 Paper Reproduction: Codebase Audit Report

**Paper Title:** Multi-Agent DRL-Based Large-Scale Heterogeneous Task Offloading for Dynamic IoT Systems  
**Authors:** Xiao He, Shanchen Pang, Haiyuan Gui, Kuijie Zhang, Nuanlai Wang, Xue Zhai  
**Journal:** IEEE Transactions on Network Science and Engineering, Vol. 12, No. 2, March/April 2025  

---

## 1. Executive Summary

This audit evaluates the current codebase against the mathematical formulations, multi-agent reinforcement learning architecture, queue scheduling mechanisms, Lyapunov optimization framework, dataset processing, and experimental protocols set forth in the target IEEE TNSE 2025 paper.

The objective of this project is to build an **honest, faithful reproduction** of the paper's algorithm and environment, running real experiments without hard-coded numbers, curve scaling, or artificial baseline performance manipulation.

## 3. Summary of Audit Findings & Priority Action Plan

1. **Phase 2 (Authoritative Config):** Create a single authoritative configuration module in `src/config.py` with all paper parameters (Table I & II).
2. **Phase 3 (Dataset Cleaning):** Build a data processing pipeline that cleans the Alibaba PAI trace to yield the 26,925 usable tasks across 1,523 GPU nodes, setting $size_{i,k}^t = \rho C_{i,k}^t < 10^8$ bits.
3. **Phase 4 & 5 (System Model & MHFQ):** Implement exact mathematical equations (1)-(18) for CPU/GPU co-processing, wireless channel gain, transmission rate, MHFQ 3-level feedback queues with time slicing, local ED execution, MES execution, and queue waiting times.
4. **Phase 6 (Lyapunov Rewards):** Replace custom reward function with paper Equations (38)-(40) balancing queue drift and processing throughput for ED, Cloud, and Team rewards.
5. **Phase 7 & 8 (Multi-Agent LRMA Architecture):** Reconstruct true CTDE multi-agent model ($N$ ED Actors + 1 Cloud Actor + Centralized Critic) with primary/target networks, soft updates, and parameter reset.
6. **Phase 9 & 10 (LSTM & Parameter Reset):** Upgrade LSTM workload predictor for multi-feature task arrival state vectors $\beta^t$ and implement parameter resetting every $\delta^{reset}=50$ slots.
7. **Phase 11 (Remove Hardcoding):** Purge all hard-coded paper numbers, artificial scaling multipliers, and fake baseline results from `generate_paper_plots.py` and log changes in `reports/removed_hardcoding.md`.
8. **Phase 12-15 (Baselines, Protocol & Metrics):** Implement real MA3MCO, L-MADDPG, and DVCCO baselines, run multi-seed evaluations ($t=1..300$ slots), and output raw CSVs and real Figures 4-10.
9. **Phase 16-20 (Reports, Colab & Verification):** Produce `reports/paper_reproduction_report.md`, ensure Colab compatibility, run unit tests and sanity checks.
